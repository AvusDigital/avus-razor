# Avus Razor v2

Stack: **Astro 4 + TypeScript + Tailwind CSS**.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```

## Antes de publicar (itens marcados com TODO)
- Logo e favicon já estão em `public/` (`logo2.png`, `logo2.svg`, `favicon.*`). Se tiver a logo oficial, troque o `logo2.png`.
- `src/data/razor.ts`: WhatsApp, endereço, horários, **preços e durações** e barbeiros reais.
- Troque as fotos do Unsplash pelas da barbearia.
- Suba a pasta completa no GitHub (inclusive `src/pages/`).

## Paleta
Carvão, osso, areia e bordô (único acento). Mude tudo em `tailwind.config.mjs`.
